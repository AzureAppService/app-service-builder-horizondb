A little more about the search

Keyword search uses a BM25 index. Hybrid search combines keyword and vector rankings with reciprocal rank fusion, without a reranker. Match labels describe the contributions observed in returned results; a successful hybrid query alone does not prove that both retrieval paths contributed.
